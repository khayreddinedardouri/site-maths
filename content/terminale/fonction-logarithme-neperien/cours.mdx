## 🎯 L'idée du chapitre

Le logarithme népérien, noté `ln`, est la fonction qui **"annule" l'exponentielle** : c'est
sa fonction réciproque. Retenir cette seule idée permet de retrouver presque toutes les
propriétés du chapitre.

## 1. Définition : `ln` est la réciproque de `exp`

Pour tout réel `a > 0`, l'équation `eˣ = a` a une unique solution. On appelle cette solution
`ln(a)` (« logarithme népérien de `a` »). Autrement dit :

```
eˣ = a  ⟺  x = ln(a)      (pour a > 0)
```

⚠️ **`ln(x)` n'existe que pour `x > 0`.** C'est la première chose à vérifier avant tout calcul
ou toute résolution d'équation avec un logarithme (on parle de **domaine de définition** ou
de **domaine d'existence**).

Comme `e⁰ = 1`, on a `ln(1) = 0`. Comme `e¹ = e`, on a `ln(e) = 1`. Et par définition même de
la réciproque :

```
e^(ln(x)) = x       ln(eˣ) = x
```

**Visuellement** : les courbes de `exp` et `ln` sont **symétriques par rapport à la droite
`y = x`** (comme toutes les fonctions réciproques l'une de l'autre).

## 2. Résoudre des équations avec `ln` et `exp`

### Exemple 1 : `ln(x) = 4`

```
ln(x) = 4  ⟺  e^(ln(x)) = e⁴  ⟺  x = e⁴
```

### Exemple 2 : `e^(3x) = 7`

```
e^(3x) = 7  ⟺  ln(e^(3x)) = ln(7)  ⟺  3x = ln(7)  ⟺  x = ln(7)/3
```

> 💡 Le réflexe est toujours le même : pour "sortir" un `x` piégé dans un exposant, on prend
> le `ln` des deux côtés. Pour "sortir" un `x` piégé dans un `ln`, on prend l'exponentielle
> des deux côtés.

## 3. La relation fonctionnelle : `ln` transforme les produits en sommes

C'est la propriété la plus utile du chapitre, pour tous `a, b > 0` :

```
ln(a × b) = ln(a) + ln(b)
```

**Conséquences directes** (à connaître par cœur) :

```
ln(a/b) = ln(a) − ln(b)          ln(1/b) = −ln(b)          ln(aⁿ) = n × ln(a)
```

### Exemple

Exprimer `ln(50)` en fonction de `ln(2)` et `ln(5)` :

```
ln(50) = ln(2 × 25) = ln(2 × 5²) = ln(2) + ln(5²) = ln(2) + 2ln(5)
```

## 4. Signe et sens de variation

La fonction `ln` est **dérivable** sur `]0 ; +∞[` et sa dérivée est très simple :

```
ln'(x) = 1/x
```

Comme `1/x > 0` pour tout `x > 0`, la fonction `ln` est **strictement croissante** sur
`]0 ; +∞[`.

**Limites aux bornes :** `lim (x→0⁺) ln(x) = −∞` et `lim (x→+∞) ln(x) = +∞`.

**Signe de `ln(x)`** (conséquence directe de la croissance et de `ln(1) = 0`) :

| `x`      | `0`  |    | `1`   |    | `+∞` |
|----------|------|----|-------|----|------|
| `ln(x)`  |      | `−` | `0`  | `+` |      |

**Comparaison** (grâce à la stricte croissance de `ln`), pour `a, b > 0` :

```
ln(a) = ln(b)  ⟺  a = b          ln(a) < ln(b)  ⟺  a < b
```

### Exemple de résolution d'inéquation

Résoudre `ln(2x − 1) ≤ ln(5)` sur son domaine de définition.

1. **Domaine** : il faut `2x − 1 > 0`, soit `x > 1/2`.
2. Par stricte croissance de `ln` : `ln(2x−1) ≤ ln(5) ⟺ 2x − 1 ≤ 5 ⟺ x ≤ 3`.
3. En combinant avec le domaine : `S = ]1/2 ; 3]`.

## 5. Dérivée de `ln(u)`

Si `u` est une fonction dérivable et **strictement positive** sur un intervalle :

```
(ln(u))'(x) = u'(x)/u(x)
```

### Exemple

Soit `f(x) = ln(x² + 1)`. Ici `u(x) = x² + 1` (toujours strictement positif) et `u'(x) = 2x`,
donc :

```
f'(x) = 2x/(x² + 1)
```

## 6. Croissances comparées : `ln` contre les puissances

Le logarithme grandit **très lentement**. Face à n'importe quelle puissance de `x`, c'est
`x` qui l'emporte :

```
lim (x→+∞) ln(x)/x = 0        lim (x→0⁺) x·ln(x) = 0
```

> 💡 À retenir dans l'ordre de "vitesse de croissance" en `+∞` : `ln(x)` est le plus lent,
> puis les puissances de `x`, puis `eˣ` est le plus rapide.

## ✅ À retenir

- `ln` = réciproque de `exp` : `ln(x) = y ⟺ eʸ = x`.
- Toujours vérifier le **domaine** (`x > 0`) avant de manipuler un `ln`.
- `ln` transforme les produits en sommes : c'est l'outil pour simplifier des écritures.
- `ln` est strictement croissante : cela permet de comparer et de résoudre équations/inéquations.
- `ln(x)/x → 0` en `+∞` : le logarithme est "battu" par toute puissance de `x`.
