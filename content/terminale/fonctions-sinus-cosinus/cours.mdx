## 🎯 L'idée du chapitre

`sin` et `cos` sont des fonctions **périodiques** : leur courbe se répète indéfiniment, comme
un motif de papier peint. Ce chapitre étudie leurs propriétés (parité, dérivée) et apprend à
résoudre des équations et inéquations qui les contiennent.

## 1. Parité et périodicité, en général

Avant de parler de `sin` et `cos`, deux notions générales très utiles :

- Une fonction `f` est **paire** si `f(−x) = f(x)` pour tout `x` : sa courbe est **symétrique
  par rapport à l'axe des ordonnées**.
- Une fonction `f` est **impaire** si `f(−x) = −f(x)` pour tout `x` : sa courbe est
  **symétrique par rapport à l'origine du repère**.
- Une fonction `f` est **périodique de période `T`** si `f(x + T) = f(x)` pour tout `x` : la
  courbe se répète tous les `T`.

> 💡 Intérêt pratique : si une fonction est paire/impaire et/ou périodique, on peut se
> contenter de l'étudier sur un intervalle plus petit, puis reconstruire le reste de la
> courbe par symétrie ou par translation.

## 2. Définition de `sin` et `cos`

Dans un repère, on place le point `M` du cercle trigonométrique associé à un réel `x`. Par
définition, les coordonnées de `M` sont `(cos(x) ; sin(x))`.

## 3. Parité et périodicité de `sin` et `cos`

- `cos` est **paire** et `2π`-périodique : sa courbe est symétrique par rapport à l'axe des
  ordonnées, et se répète tous les `2π`.
- `sin` est **impaire** et `2π`-périodique : sa courbe est symétrique par rapport à l'origine,
  et se répète tous les `2π`.

Cela signifie qu'il suffit d'étudier chacune de ces deux fonctions sur un intervalle de
longueur `2π` (par exemple `[−π ; π]`) pour connaître toute la courbe.

## 4. Dérivées de `sin` et `cos`

```
sin'(x) = cos(x)          cos'(x) = −sin(x)
```

> 💡 Moyen mnémotechnique : dériver `sin` donne `cos` (sans changement de signe) ; dériver
> `cos` donne `−sin` (avec un changement de signe). Si on dérive deux fois, on retombe sur
> l'opposé de la fonction de départ (`sin'' = −sin`, `cos'' = −cos`).

**Pour une fonction composée** `sin(u)` ou `cos(u)`, avec `u` dérivable :

```
(sin(u))'(x) = u'(x) × cos(u(x))          (cos(u))'(x) = −u'(x) × sin(u(x))
```

### Exemple

Soit `f(x) = sin(4x − 1)`. Ici `u(x) = 4x − 1`, donc `u'(x) = 4` :

```
f'(x) = 4 × cos(4x − 1)
```

## 5. Résoudre une équation trigonométrique

**Règles fondamentales** (avec `k` un entier relatif quelconque) :

```
cos(x) = cos(a)  ⟺  x = a + 2kπ  ou  x = −a + 2kπ
sin(x) = sin(a)  ⟺  x = a + 2kπ  ou  x = π − a + 2kπ
```

### Exemple

Résoudre `sin(x) = 1/2` dans `ℝ`. On repère que `1/2 = sin(π/6)`, donc :

```
sin(x) = 1/2  ⟺  x = π/6 + 2kπ  ou  x = π − π/6 + 2kπ = 5π/6 + 2kπ,  k ∈ ℤ
```

## 6. Résoudre une inéquation trigonométrique

**Règles** (avec `a ∈ ℝ`) :

```
cos(x) ≤ cos(a)  ⟺  a + 2kπ ≤ x ≤ 2π − a + 2kπ
sin(x) ≤ sin(a)  ⟺  −π − a + 2kπ ≤ x ≤ a + 2kπ
```

### Exemple

Résoudre `cos(2x) ≥ 1/2` dans `[−π/2 ; π/2]`.

On pose `X = 2x`, donc `X ∈ [−π ; π]`. Or `1/2 = cos(π/3)`, donc en réécrivant l'inégalité
dans l'**autre** sens (`cos(X) ≥ cos(π/3)`) :

```
cos(2x) ≥ 1/2  ⟺  −π/3 ≤ 2x ≤ π/3  ⟺  −π/6 ≤ x ≤ π/6
```

> 💡 Le passage par une variable intermédiaire (`X = 2x`) est très souvent utile pour ne pas
> se tromper avec les bornes : on résout d'abord pour `X`, puis on revient à `x` à la toute fin.

## ✅ À retenir

- `cos` est paire, `sin` est impaire ; toutes les deux sont `2π`-périodiques.
- `sin' = cos` et `cos' = −sin` (à ne jamais confondre !).
- Pour une équation/inéquation, on repère d'abord un angle "connu" `a` tel que
  `cos(a)` ou `sin(a)` vaut la valeur cherchée, puis on applique la formule adaptée.
