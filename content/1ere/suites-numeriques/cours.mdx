## Définition

Une **suite numérique** est une fonction qui à chaque entier naturel `n` associe un
nombre réel noté `u(n)` ou `uₙ`.

## Suites arithmétiques

Une suite est **arithmétique** de raison `r` si, pour tout entier `n` :

```
u(n+1) = u(n) + r
```

Le terme général s'écrit `u(n) = u(0) + n × r`.

## Suites géométriques

Une suite est **géométrique** de raison `q` si, pour tout entier `n` :

```
u(n+1) = q × u(n)
```

Le terme général s'écrit `u(n) = u(0) × qⁿ`.

## À retenir

- Une suite arithmétique **ajoute** toujours la même quantité.
- Une suite géométrique **multiplie** toujours par la même quantité.
